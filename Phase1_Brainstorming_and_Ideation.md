Phase 1: Brainstorming & Ideation

Project Title
Standard Laptop Procurement Automation

Problem Statement
In many organizations, laptop procurement requests are handled manually. After approval, tasks must be created and assigned manually, which can cause delays, errors, and inefficient tracking.

Proposed Solution
Develop an automated workflow in ServiceNow that creates a Catalog Task automatically when a Standard Laptop request is approved and assigns the task to the Hardware Team.

Project Objectives
- Automate laptop procurement processing.
- Reduce manual effort.
- Improve task tracking and visibility.
- Ensure faster assignment to the Hardware Team.
- Minimize human errors.

Scope of the Project
The project focuses on automating the Standard Laptop procurement process using ServiceNow Service Catalog and Flow Designer.

Expected Benefits
- Faster processing of laptop requests.
- Automatic task creation.
- Better workflow management.
- Reduced manual intervention.
- Improved efficiency and productivity.

Expected Outcome
When a user requests a Standard Laptop and the request is approved, a Catalog Task will be created automatically and assigned to the Hardware Team for laptop configuration.
