Phase 2: Requirement Analysis

Project Title
Standard Laptop Procurement Automation

Functional Requirements
1. Users should be able to request a Standard Laptop through the Service Catalog.
2. The request should go through an approval process.
3. After approval, the system should automatically create a Catalog Task.
4. The Catalog Task should be assigned to the Hardware Team.
5. The Hardware Team should be able to view and process the task.

Non-Functional Requirements
1. The system should be reliable and accurate.
2. The workflow should be easy to use.
3. The process should reduce manual effort.
4. The system should provide proper task tracking.

Hardware Requirements
- Computer/Laptop
- Minimum 4 GB RAM
- Stable Internet Connection

Software Requirements
- ServiceNow Platform
- Web Browser (Chrome, Edge, Firefox)
- Active ServiceNow Instance

Users of the System
- End Users
- Approvers
- Hardware Team
- ServiceNow Administrators

Requirement Summary
The project requires ServiceNow Service Catalog, Approval Process, Flow Designer, and Catalog Task Management to automate laptop procurement.
