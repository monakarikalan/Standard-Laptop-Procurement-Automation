Project Documentation Phase

Project Title

Standard Laptop Procurement Automation

Project Description

The Standard Laptop Procurement Automation project is developed using ServiceNow Flow Designer. The purpose of this project is to automate the laptop procurement process by creating a Catalog Task automatically when a Standard Laptop request is submitted and approved. This reduces manual work and improves efficiency.

Project Objectives

1. Automate the Standard Laptop request process.
2. Reduce manual intervention in task creation.
3. Assign tasks automatically to the Hardware Team.
4. Improve workflow efficiency and accuracy.
5. Demonstrate automation using ServiceNow Flow Designer.

Tools and Technologies Used

- ServiceNow
- Flow Designer
- Service Catalog
- Catalog Task
- Workflow Studio
- GitHub

Modules Used

1. Service Catalog
   Used to submit Standard Laptop requests.

2. Requested Items (RITM)
   Used to track user requests.

3. Flow Designer
   Used to automate the workflow.

4. Catalog Task
   Used to create and assign tasks automatically.

Workflow Summary

Step 1:
User submits a Standard Laptop request through the Service Catalog.

Step 2:
The request is approved.

Step 3:
The Flow Designer trigger activates automatically.

Step 4:
A Catalog Task is created.

Step 5:
The task is assigned to the Hardware Team.

Step 6:
The Hardware Team configures and delivers the laptop.

Expected Output

After approval of a Standard Laptop request, a Catalog Task is automatically created and assigned to the Hardware Team without manual intervention.

Benefits of the Project

- Saves time.
- Reduces manual effort.
- Improves process efficiency.
- Ensures task consistency.
- Supports workflow automation.

Project Outcome

The Standard Laptop Procurement Automation flow was successfully designed, developed, and tested in ServiceNow. The automation process worked as expected and demonstrated the effective use of Flow Designer.

Conclusion

This project successfully automates the Standard Laptop procurement process using ServiceNow Flow Designer. The automated workflow creates Catalog Tasks efficiently and helps organizations manage laptop requests in a structured and reliable manner.
