 Standard Laptop Procurement Automation

Project Overview
This project automates the procurement process for standard laptops using ServiceNow Flow Designer.

Objective
To automatically create and assign a Catalog Task to the Hardware Team after approval of a Standard Laptop request.

Technologies Used
- ServiceNow
- Service Catalog
- Flow Designer
- Catalog Tasks

Workflow
1. User orders Standard Laptop.
2. Approval process starts.
3. Request gets approved.
4. Flow Designer triggers automatically.
5. Catalog Task is created.
6. Task is assigned to Hardware Team.
7. Hardware Team configures the laptop.

Benefits
- Reduces manual work.
- Faster task creation.
- Better tracking.
- Improved efficiency.
