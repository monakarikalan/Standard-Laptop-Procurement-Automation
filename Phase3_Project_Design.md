Phase 3: Project Design

Project Title
Standard Laptop Procurement Automation

System Design

The project is designed using ServiceNow Service Catalog and Flow Designer.

Workflow

1. User submits a Standard Laptop request.
2. Approval process is triggered.
3. Request is approved by the approver.
4. Flow Designer is triggered automatically.
5. Catalog Task is created.
6. Task is assigned to the Hardware Team.
7. Hardware Team configures and provides the laptop.

Components Used

Service Catalog
Used to create and manage the Standard Laptop request.

Approval Process
Used to approve the laptop request.

Flow Designer
Used to automate the workflow.

Catalog Task
Used to assign work to the Hardware Team.
